$ ros2 param set --help
usage: ros2 param set [-h] [--spin-time SPIN_TIME] [-s] [--no-daemon]
                      [--include-hidden-nodes] [--timeout N]
                      node_name parameter_name value

Set parameter

positional arguments:
  node_name             Name of the ROS node
  parameter_name        Name of the parameter
  value                 Value of the parameter

options:
  -h, --help            show this help message and exit
  --spin-time SPIN_TIME
                        Spin time in seconds to wait for discovery (only
                        applies when not using an already running daemon)
  -s, --use-sim-time    Enable ROS simulation time
  --no-daemon           Do not spawn nor use an already running daemon
  --include-hidden-nodes
                        Consider hidden nodes as well
  --timeout N           Wait for N seconds until node becomes available
                        (default 1 sec)
[exit 0]
